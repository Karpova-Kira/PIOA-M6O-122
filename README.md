# Система управления базами данных (СУБД)

Объектно-ориентированная СУБД для управления данными с поддержкой нескольких таблиц и полным набором CRUD-операций.

## Структура проекта
```text
pioa-m6o-122bv-25/
├── src/                    # Исходный код проекта
│   └── db/                 # Основной пакет приложения
│       ├── __init__.py     # Файл-маркер пакета (может быть пустым)
│       ├── __main__.py     # Точка входа в приложение

│       └── backend/        # Подпакет с бизнес-логикой
│           ├── __init__.py # Файл-маркер подпакета
│           ├── errors.py # Пользовательские исключения
│           └── memory.py   # Модуль работы с данными (CRUD-операции)
├── tests/
│ ├── init.py # Маркер пакета тестов
│ └── test_memory.py # Модульные тесты
```

## Назначение модулей

**`src/db/__main__.py`** — точка входа, запускает TUI.

**`src/db/tui.py`** — текстовый пользовательский интерфейс (класс `DatabaseTUI`). Отвечает за вывод меню, ввод данных и взаимодействие с пользователем.

**`src/db/backend/memory.py`** — ядро СУБД:
  Класс `MemoryDatabase` — управляет созданием, хранением и переключением между несколькими таблицами.
  
  Класс `Table` — отвечает за хранение записей одной таблицы, управление её схемой (колонками) и выполнение CRUD-операций.

**`src/db/backend/errors.py`** — пользовательские исключения для обработки нештатных ситуаций (DatabaseError, TableAlreadyExistsError, TableNotFoundError, MissingColumnError).

**`tests/test_memory.py`** — модульные тесты

## Функциональность

### Поддержка нескольких таблиц
   - Динамическое создание таблиц с произвольным набором колонок (create_table).
   - Просмотр списка всех существующих в БД таблиц (list_tables).
   - Переключение между таблицами в интерактивном режиме для выполнения операций.
   - Просмотр текущей схемы (набора колонок) выбранной таблицы.

### CRUD-операции (для каждой таблицы)

| Операция | Метод | Описание |
|----------|-------|----------|
| **Create** | `create_record()` | Добавление записи с проверкой возраста и пола |
| **Read** | `select_record()` | Поиск по одному или нескольким фильтрам |
| **Update** | `update_record()` | Обновление существующей записи по ID |
| **Delete** | `delete_record()` | Удаление записи по ID с подтверждением |

### Валидация данных
- Возраст не может быть отрицательным
- Пол принимает значения: `M`, `F`, `m`, `f`, `м`, `ж`


### Инструкция по запуску
Требования
Python версии 3.10 или выше

Шаги для запуска
Откройте терминал (командную строку, PowerShell или любой другой)

Перейдите в корневую директорию проекта (папку, внутри которой находится каталог src):
`cd путь/до/папки/с_проектом`
Запустите приложение:
`python -m src.db`
