# Система управления базой данных студентов

Консольное приложение для ведения базы данных студентов с поддержкой полного набора CRUD-операций (создание, чтение, обновление, удаление).

## Структура проекта
project/
├── src/ # Исходный код проекта
│ └── db/ # Основной пакет приложения
│ ├── init.py # Файл-маркер пакета (может быть пустым)
│ ├── main.py # Точка входа в приложение
│ ├── tui.py # Модуль текстового интерфейса пользователя
│ └── backend/ # Подпакет с бизнес-логикой
│ ├── init.py # Файл-маркер подпакета
│ └── memory.py # Модуль работы с данными (CRUD-операции)
└── README.md # Документация проекта

### Назначение модулей

| Файл | Назначение |
|------|------------|
| `src/db/__main__.py` | Точка входа. Запускает текстовый интерфейс пользователя. |
| `src/db/tui.py` | Текстовый пользовательский интерфейс (Text User Interface). Отвечает за вывод меню, ввод данных, отображение результатов и взаимодействие с пользователем. |
| `src/db/backend/memory.py` | Бэкенд-модуль хранения данных. Содержит все операции с данными: создание, чтение, обновление, удаление записей. Данные хранятся в оперативной памяти в виде списка кортежей. |
| `src/db/__init__.py` | Пустой файл, обозначающий директорию `db` как пакет Python. |
| `src/db/backend/__init__.py` | Пустой файл, обозначающий директорию `backend` как подпакет. |

## Функциональность

Приложение поддерживает следующие операции:

### 1. Добавление записи (Create)
- Создание новой записи о студенте
- Автоматическая проверка уникальности ID (идентификатор не должен повторяться)
- Валидация возраста (не может быть отрицательным)
- Валидация пола (только 'м' или 'ж', регистр букв не важен)

### 2. Просмотр всех записей (Read)
- Вывод полного списка всех студентов в базе данных
- Отображение всех полей записи: ID, имя, фамилия, возраст, пол

### 3. Поиск записей по фильтру (Read with filters)
- Поиск по одному или нескольким критериям:
  - ID студента
  - Имя
  - Фамилия
  - Возраст
  - Пол
- Можно пропустить любой фильтр (оставить пустым)
- Поиск по полу работает независимо от регистра букв ('ж', 'Ж', -> найдёт всех женщин)

### 4. Обновление записи (Update)
- Изменение данных существующего студента по ID
- Возможность обновить любое поле (или несколько полей сразу)
- Поля, оставленные пустыми, не изменяются
- Валидация новых данных (возраст, пол)

### 5. Удаление записи (Delete)
- Удаление студента по ID
- Подтверждение перед удалением (защита от случайного удаления)
- Информативное сообщение о результате операции

## Формат данных

Каждая запись о студенте имеет следующую структуру:

| Поле | Тип | Описание | Пример |
|------|-----|----------|--------|
| id | `int` | Уникальный идентификатор | `1` |
| first_name | `str` | Имя | `"qwe"` |
| second_name | `str` | Фамилия | `"rty"` | 
| age | `int` | Возраст (неотрицательный) | `2` |
| sex | `str` | Пол ('м' или 'ж') | `"м"` |

Данные хранятся в оперативной памяти в виде списка кортежей:
```python
Student: list[StudentRecord] = []
```

### Инструкция по запуску
Требования
Python версии 3.10 или выше

Шаги для запуска
Откройте терминал (командную строку, PowerShell или любой другой)

Перейдите в корневую директорию проекта (папку, внутри которой находится каталог src):
`cd путь/до/папки/с_проектом`
Запустите приложение:
`python -m src.db`
