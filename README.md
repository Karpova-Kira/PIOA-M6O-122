# Система управления базами данных (СУБД)

Объектно-ориентированная СУБД с поддержкой in-memory и файлового хранения (JSON и CSV).

## Назначение модулей

**`src/db/backend/database.py`** — абстрактный класс, задающий общий интерфейс для всех реализаций БД.

**`src/db/backend/table.py`** — класс Table, отвечающий за структуру таблицы и операции над записями.

**`src/db/backend/memory.py`** — in-memory реализация (данные хранятся в оперативной памяти и теряются после закрытия программы).

**`src/db/backend/file.py`** — JSON-реализация (данные сохраняются в файлы JSON в папке `data/`).

**`src/db/backend/csv_file.py`** — CSV-реализация (данные сохраняются в файлы CSV в папке `data_csv/`).

**`src/db/backend/errors.py`** — пользовательские исключения.

**`src/db/tui.py`** — текстовый интерфейс с выбором типа БД при запуске.

## Функциональность

### Типы баз данных

| Тип | Хранение | Сохранение данных | Папка |
|-----|----------|-------------------|-------|
| **In-memory** | Оперативная память | Не сохраняются | — |
| **File (JSON)** | JSON-файлы | Сохраняются | `data/` |
| **File (CSV)** | CSV-файлы | Сохраняются | `data_csv/` |

### Поддерживаемые операции

- **Создание таблицы** — с указанием имени и полей
- **Добавление записи** — с проверкой типов и обязательных полей
- **Просмотр всех записей** — вывод содержимого таблицы
- **Поиск по фильтру** — по одному или нескольким полям
- **Обновление записи** — изменение существующих данных
- **Удаление записи** — с подтверждением операции
- **Просмотр структуры таблицы** — список полей и их типов

### Инструкция по запуску
Требования
Python версии 3.10 или выше

Шаги для запуска
Откройте терминал (командную строку, PowerShell или любой другой)

Перейдите в корневую директорию проекта (папку, внутри которой находится каталог src):
`cd путь/до/папки/с_проектом`
Запустите приложение:
`python -m src.db`
